# Frontend Mentor Challenges Reflection

## 1. How did using Figma designs as references affect your coding process?

Using the Figma design helped me a lot because I had something to look at while coding. Instead of trying to figure out what the website should look like, I could focus on building it and matching the design. It made things easier because I knew where everything was supposed to go and what colors and fonts to use.

## 2. What challenges did you encounter when aligning your code with the design specifications?

The hardest part was getting everything to look the same as the design. Sometimes the spacing or sizing looked right in my code but a little different in the browser. I also had to make sure the layout looked good on different screen sizes and didn't break when I resized the page.

## 3. How can the feedback and community resources on Frontend Mentor help you improve as a developer?

Frontend Mentor has a lot of people sharing their solutions and ideas, which can help me learn new ways to solve problems. Looking at other people's projects can show me better coding techniques and help me improve my own work. The feedback is also useful because it can point out mistakes or things I could do better next time.
